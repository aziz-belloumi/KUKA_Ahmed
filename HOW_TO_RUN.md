# How to Run

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Project
```bash
npm run dev
```

### 3. Open in Browser
Open `http://localhost:5173/`

---

### (Optional) Production Build
```bash
npm run build
npm run preview
```

### (Optional) Re-convert CAD Model
```bash
pip install -r requirements.txt
python convert_step_to_robot_glb.py
```
